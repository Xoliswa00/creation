5. PLATFORM BILLING SYSTEM (SYSTEM OWNER -> TENANT COMPANIES)
================================================================================

This is the billing layer between you (the developer/system owner) and the
businesses using the SaaS platform.

MIGRATIONS:
- Alter subscriptions table: add company_id, client_id, invoice_id, frequency
  (monthly/quarterly/yearly), next_invoice_date, active bool
- Create platform_invoices (id, company_id FK, invoice_number unique, plan,
  amount decimal, status enum[unpaid,paid,overdue,cancelled] default unpaid,
  due_date date, billing_period_start date, billing_period_end date,
  paid_at timestamp nullable, payment_method nullable,
  payment_reference nullable, notes text nullable)
- Alter companies table: add grace_period_ends_at timestamp nullable,
  suspended_at timestamp nullable, last_billing_date timestamp nullable

MODEL PlatformInvoice: casts, isOverdue(), days_overdue accessor,
  status_badge accessor (returns label + Tailwind class), static
  generateNumber() (format: PI-YYYYMM-0001)

MODEL Company updates: add new fillable fields + casts;
  platformInvoices() hasMany; unpaidPlatformInvoices() scope;
  static planAmount(string $plan) (basic=299, premium=599, enterprise=1299);
  isInGrace(), graceDaysLeft(), billingStatusLabel(), billingStatusClass()

SERVICE PlatformBillingService:
  generateInvoice(Company): creates invoice due in 7 days, updates
    last_billing_date, notifies owner via BillingInvoiceCreatedNotification
  runDailyCheck():
    1. Mark unpaid -> overdue where due_date < today
    2. For newly overdue (no grace set): set grace_period_ends_at = now()+5days,
       notify via BillingGracePeriodStartedNotification
    3. For companies in grace: at 2 days left and 1 day left, notify via
       BillingGracePeriodExpiringNotification
    4. For companies where grace_period_ends_at <= now(): set status=suspended,
       suspended_at=now(), clear grace, notify via
       BillingServiceSuspendedNotification
  recordPayment(PlatformInvoice, method, reference): mark paid, restore company
    to active, clear grace/suspension fields, if was suspended notify via
    BillingServiceReactivatedNotification

5 NOTIFICATION CLASSES (DB + mail):
  BillingInvoiceCreatedNotification
  BillingGracePeriodStartedNotification
  BillingGracePeriodExpiringNotification
  BillingServiceSuspendedNotification
  BillingServiceReactivatedNotification

COMMAND billing:check (app/Console/Commands/CheckPlatformBilling.php):
  calls PlatformBillingService@runDailyCheck()

SCHEDULER in routes/console.php:
  Schedule::command('billing:check')->dailyAt('08:00');

MIDDLEWARE CheckCompanySuspension: appended to web group; if company is
  suspended, redirect to /billing with error flash — EXCEPT allow through:
  billing*, notifications*, logout; system admins bypass entirely.
  Register alias company.suspension in bootstrap/app.php

CONTROLLER BillingController:
